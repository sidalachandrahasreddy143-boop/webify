# Webify

A mobile-first public agency website built with Vite, React, TypeScript, Tailwind CSS and lightweight CSS device artwork. It includes six internal template demos, a filterable demo portfolio, accessible FAQs, draft legal pages and direct email/phone contact links.

## Run locally

```bash
npm install
npm run dev
npm run build
```

Project discussions start through the direct email or phone links in the header, template previews and footer. The website does not provide an inquiry form or write new submissions to Supabase. Existing Supabase data is not deleted.

## Before public launch

- Replace the three clearly marked testimonial placeholders only with verified, permissioned client quotes.
- Have the Privacy Policy and Terms of Service drafts reviewed and approved; they are explicitly labelled as placeholders.
- Confirm package scope, taxes, timelines, ownership/handover and third-party costs in each real project quote.
- Replace or edit demo template copy and imagery as required. The current examples are not represented as live client projects.
- Add a production domain, social preview image and verified search/sitemap metadata when the final domain is known.
